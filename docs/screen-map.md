# 화면 구성도

이 사이트가 위에서 아래로 무엇을 보여 주고, 그 글이 어디서 오는지 적은 문서입니다.
"어떻게 동작하나"(엔진·파티클·번들)는 [README](../README.md)에 있고, 여기는 **무엇이 어디에
있는지**만 다룹니다.

라우트는 `/` 하나입니다. 그 아래 열 개 블록이 한 문서로 이어져 있고, 오라클과 아잉만
그 흐름 위에 떠 있습니다.

---

## 한눈에

```
┌─ <html lang="ko">
│  ├─ .skip            본문으로 건너뛰기 (탭 첫 입력에만 나타남)
│  └─ #root
│     ├─ .sky           하늘 배경 (fixed, z-index -1, aria-hidden)
│     │
│     ├─ <Cover>        ① 커버 — 이름판 · 오라클 · 통계 · 스크롤 안내
│     │
│     ├─ <main id="main">
│     │   ├─ <World>       ② 픽셀 여정 — 다섯 장면 (기원·검증·규율·지능·정합성)
│     │   ├─ <Footprint>   ③ 저장소 발자국 — 세 저장소 기여도 막대
│     │   ├─ <Media>       ④ 영상·오디오 — 파이프라인 + 4년 이력
│     │   ├─ <Sharing>     ⑤ 공유 로그 — 팀 채널에 올린 글 9건
│     │   ├─ <Principles>  ⑥ 일하는 방식 — 원칙 3개
│     │   └─ <CharacterKit>⑦ 마스코트 킷 — 3D 뷰어 + 모션·표정·액션 시트
│     │
│     ├─ <Colophon>     ⑧ 콜로폰 — GitHub·YouTube 피드 · 메일
│     └─ <Guide>        아잉 — 화면 오른쪽 아래 고정, 스크롤 따라 대사 교체
│
└─ (portal → body)     오라클 판 + 파티클 캔버스 + 스크림
```

## 전역 요소

### 하늘 (`.sky`)

`position: fixed`로 문서 전체 뒤에 깔린 한 장입니다. `/assets/sky.webp`와 CSS 그라디언트를
겹쳐 쓰고, 스크롤해도 움직이지 않습니다. 모든 섹션이 이 위에 유리처럼 얹힙니다.

### 아잉 (`<Guide>` · 클라이언트)

화면 오른쪽 아래에 붙어 다니는 마스코트입니다. **누를 것은 접기 버튼 하나뿐**이고,
지금 보고 있는 블록을 읽어 그 장면을 설명합니다.

- 무대 판별: `useStage`가 `[data-stage]` 블록 중 **화면 세로 한복판을 덮고 있는 것**을 고릅니다.
  문서 맨 아래에서는 마지막 블록을 집습니다.
- 대사: `lib/guideScript.ts`의 `SCRIPT[stage]`. 12개 무대 각각에 대사 한 줄과 포즈/모션이 짝지어 있습니다.
- 그림: 기본은 정지 포즈(`/mascot/pose/*.webp`), 모션을 허용한 방문자에게만 애니메이션
  WebP(`/mascot/motion/*.webp`)로 바뀝니다. `prefers-reduced-motion`을 첫 페인트부터 지킵니다.

| 무대 | 아잉이 하는 말 (요지) |
|---|---|
| `cover` | 자기소개, 지나갈 곳이 다섯 군데 |
| `genesis` | 등불 열넷 = 언어 14개, 커밋 98% |
| `immunity` | 흔들리지 않는 다리, 같은 검사 열 번 → 플레이크 0 |
| `gatehouse` | 열쇠구멍 하나 = 권한 체크를 한 곳에 |
| `observatory` | 갈라지는 물길 = LLM fallback 체인 |
| `vault` | 자물쇠 둘·우편함 = Outbox, 돈이 걸린 곳 |
| `footprint` | 막대 길이는 진짜 커밋 점유율 |
| `media` | ZIVO 이전 이야기, 영상 4년째 |
| `sharing` | 링크만 던지지 않고 먼저 써 보고 올린다 |
| `principles` | 규칙은 문서보다 도구에 |
| `kit` | 자기 얘기, three.js·Unity에서 써도 된다 |
| `colophon` | GitHub·유튜브에 요즘 만드는 게 올라온다, 연락은 메일로 |

| 요소 | 내용 |
|---|---|

| `.cue` | "스크롤하면 이 이야기 안으로 들어갑니다" → `#world` 앵커 |

### 오라클 (`<Oracle>` · 클라이언트)

**검색창이 그 자리에서 자라 채팅창이 되는** 판입니다. 페이지 이동도 레이어 교체도 없습니다.

- 접힌 모습: 플레이스홀더가 신기루처럼 맺혔다 증발하며 예시 질문 6개를 돌립니다
  (`iron은 어떤 개발자인가요?`, `권한 시스템은 어떻게 설계했나요?` 등).
- 펼친 모습: 헤더(`iron wiki` + 현재 엔진 상태) · 로그 · 입력창.
- 판은 `body`에 portal로 붙고, 열리면 `#root`를 `inert`로 재웁니다.
- 커버를 벗어나면 판이 비켜섭니다(`is-away`).

답을 만드는 층은 셋이고, 위에서부터 되는 것을 씁니다 (`components/oracle/brain.ts`):

| 층 | 표시 | 설명 |
|---|---|---|
| Ollama | `Ollama · 이 컴퓨터에서` | `localhost:11434`가 열려 있으면 |
| 브라우저 모델 | `Qwen3 0.6B · 브라우저 안에서` | 워커에서 ONNX 다운로드·실행, 진행률을 헤더에 표시 |
| 위키 | `위키에서 직접 인용` | 항상 되는 바닥. `lib/wiki.ts`의 **28개 청크**에서 검색 |

## ② 픽셀 여정 — `<World>`

이력서에서 할 말이 가장 많은 부분입니다. 다섯 장소를 스크롤로 걸어서 지나갑니다.

글과 스크롤 길이는 **서버가 그린 DOM**이고, 엔진(`lib/pixel-journey.ts`)은 그 위에 그림만
얹습니다 — 엔진이 없어도, JS를 안 돌려도 다섯 장은 그대로 읽힙니다.

맨 위에 다섯 장소로 가는 앵커 목록(`.px-route`)이 있고, 각 장면은
`번호 / 아이브로우 / 제목 / 본문 / 태그` 구조입니다.

| # | id · 라벨 | 아이브로우 | 제목 | 태그 |
|---|---|---|---|---|
| 01 | `genesis` 기원 | FRONT · 0 → 1 | 언어 14개를 혼자 띄웠다 | Next.js 16 · React 19 / 1,947 커밋 / 98% / PR 440 |
| 02 | `immunity` 검증 | FRONT · QUALITY | 플레이크 0으로 굳혔다 | `--repeat-each=10` burn-in / 외부 의존 0 / 방법론 문서화 |
| 03 | `gatehouse` 규율 | ADMIN · BACK | 권한을 빠뜨릴 수 없는 구조로 | RBAC + GBAC + ABAC / shared 코어 713커밋 / ArchUnit · codemod |
| 04 | `observatory` 지능 | BACK · PERF · AI | 느려지는 곳과 멈추는 곳을 같이 막았다 | OpenSearch Bulk API / CircuitBreaker 43지점 / 호텔 도메인 227커밋 |
| 05 | `vault` 정합성 | BACK · ADMIN | 돈이 걸린 곳은 유실을 먼저 설계한다 | DDD / Hexagonal / Outbox + ShedLock / 테스트 101건 |

- 다섯 본문은 각자 완결된 카드가 아니라 **이어지는 한 편**입니다. 문단 끝마다 다음 장면이
  왜 필요했는지를 한 줄로 남깁니다 (혼자 만들었으니 검증이 필요했고 → 사람이 늘었으니
  규율이 필요했고 → 안 멈추게 했으니 안 새게 만들 차례).
- 마지막 장면에만 CTA 두 개: **메일 보내기** / **저장소 기여도 보기**(`#footprint`).
- 장면별 스크롤 길이(뷰포트 배수): 1.5 · 1.25 · 1.45 · 1.45 · 1.7 — 합 **7.35**.
  실측(900px 기준)으로 1,350 / 1,125 / 1,305 / 1,305 / 2,430px입니다. 마지막 `vault`가
  배수(1.7)보다 긴 것은 CTA 블록이 얹히기 때문입니다.
- 다섯 씬을 감싸는 바깥 `<div data-stage="world">`는 **무대가 아니라 표식**입니다 —
  첫 씬 직전의 경계에서만 잡히고, `useStage`가 `genesis`로 바꿔 넘깁니다.
- 출처: `lib/worldConfig.ts`의 `sections`.

## ④ 영상·오디오 — `<Media>`

ZIVO 아홉 달과 겹치지 않는 축이라 여정 밖에 따로 세운 섹션입니다. 2022년 숏폼 앱에서
시작해 이 포트폴리오의 엔진 교체까지 4년 이어집니다.

- 리드: 숏폼 앱의 업로드·변환·내보내기 → 실시간 통역 오디오 → 이 사이트의 배경을
  영상에서 픽셀로.
- 업로드 파이프라인 6단계(세로 알약, 사이는 그려진 1px 선):
  `촬영 · 구간 선택` → `FFmpeg 자르기 (클라이언트)` → `S3 업로드` → `MediaConvert 변환`
  → `CloudFront 배포` → `앱 · 파트너스 웹 재생`
- 이력 4건:

| 시기 | 소속 | 제목 |
|---|---|---|
| 2022–2023 | ㈜데브락 · 여기가게 · 2인 | 숏폼 앱, 올리는 쪽과 보는 쪽을 같은 파이프라인 위에 |
| 2024–2025 | 애자일그로스㈜ · AI Interpreter | 늦게 도착한 통역 구간만 골라 버리기 |
| 2024 | Lossless Cut · Electron | 래퍼가 만들어 주는 명령을 안 쓰기 |
| 2026 | 이 포트폴리오 | 영상 세계를 버리고 픽셀로 |

> **미완**: `MEDIA_SHOTS`에 여기가게 앱 화면 두 장(`/assets/yeogigage/*.webp`)이 정의돼
> 있지만 파일이 저장소에 없습니다. 컴포넌트가 빌드 시점에 존재를 확인해 없으면 걸지
> 않으므로 지금은 파이프라인만 보입니다. 파일을 넣으면 다음 빌드에서 붙습니다.

## ⑥ 일하는 방식 — `<Principles>`

제목 **"이렇게 일합니다"**. 번호가 붙은 원칙 셋, 가운데 정렬.

1. **규칙은 문서보다 도구에 넣습니다.** — 의존 방향은 ArchUnit, 디자인 토큰은 codemod,
   권한은 훅 하나가 봅니다.
2. **실패 비용이 큰 곳은 실패부터 그립니다.** — 결제는 취소·이탈 흐름 먼저, LLM에는
   fallback 체인, 쿠폰에는 Outbox를 먼저.
3. **같은 버그를 두 번 만나지 않게 고칩니다.** — 이중 토스트는 전역 `onError` 규약으로,
   E2E 플레이크는 하이드레이션 유틸로 원인을 없앤 뒤 burn-in으로 셌습니다.

출처: `lib/content.ts`의 `PRINCIPLES`.

## ⑦ 마스코트 킷 — `<CharacterKit>`

제목 **"여기까지 안내한 고양이는, 쓸 수 있는 에셋입니다"**. 지금까지 안내하던 아잉이
장식이 아니라 실제 에셋임을 보여 주는 섹션입니다.

| 블록 | 내용 |
|---|---|
| `<Live3D>` | `3d/aing-lite.glb`(205kB)를 돌리는 3D 뷰어. 페이지 안은 미리보기라 lite면 충분합니다 |
| 모션 | **6종** — celebrate · idle · jump · think · type · wave (알파 애니메이션 WebP) |
| 표정 | **16종** — cheer · confused · focused · happy · love · neutral … (알파 컷아웃) |
| 액션 | **16종** — bow · carry · celebrate · coding · idle · jump … (알파 컷아웃) |

매니페스트(`public/mascot/aing-kit.json`)는 브라우저에서 fetch하지 않고 **빌드 타임에

## 화면 밖 — 기계가 읽는 표면

사람에게 보이는 것과 **같은 상수**에서 나오므로 따로 관리할 사본이 없습니다.

| 주소 | 형식 | 무엇 |
|---|---|---|
| `/iron.md` | `text/markdown` | 이력서 전문. 정본 마크다운 주소 |
| `/llms.txt` | `text/plain` | 요약 + 어디에 무엇이 있는지 |
| `/llms-full.txt` | `text/plain` | 전문 |
| `/sitemap.xml` | XML | `/` · `/iron.md` · `/llms.txt` |
| `/robots.txt` | text | AI 크롤러 16종을 **이름으로 적어** 허용 |

- `<head>`에 `rel="alternate"`로 `/iron.md`(text/markdown)와 `/llms.txt`(text/plain)를 알립니다.
- `proxy.ts`가 `Accept: text/markdown` 요청을 홈에서 `/iron.md`로 rewrite합니다(리다이렉트가
  아니라서 주소는 그대로). 다만 공유 캐시 한계 때문에 이건 편의 기능이고, 에이전트에게
  약속하는 정본은 `/iron.md`입니다.
- 홈에는 JSON-LD(`lib/jsonld.ts`)가 `Person` 스키마로 들어갑니다 —
  `sameAs`는 GitHub·YouTube.

## 접근성·성능에서 화면에 드러나는 것

- **본문으로 건너뛰기**: 탭을 처음 누르면 왼쪽 위에 나타납니다. 키보드 사용자는 커버의
  검색창·통계·안내를 지나지 않고 바로 `#main`으로 갑니다.
- **모션 축소**: 아잉은 정지 포즈가 기본이고, 허용한 방문자에게만 루프로 바뀝니다.
- **JS 없이**: 픽셀 여정 다섯 장, 저장소 막대, 모든 섹션 글이 그대로 읽힙니다. 앵커 이동도
  됩니다. 안 되는 것은 오라클 대화와 3D 뷰어뿐입니다.
- **폰트**: 표제용 Instrument Serif만 self-host, 본문 한글은 Pretendard 동적 서브셋을
  `media="print"`로 받아 첫 페인트를 막지 않습니다.
